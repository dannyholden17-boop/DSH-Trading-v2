# DSH Trading v2 — Obsidian vault

This folder **is** an Obsidian vault. It captures the whole DSH v2 project as
linked notes, a database, and a visual canvas.

## Open it

1. Download / clone this repo.
2. In Obsidian: **Open folder as vault** → select this `obsidian-vault` folder.
3. Start at [[DSH]] (the home note), then open **Architecture.canvas** and
   **Engines.base**.

## What's inside

| Path | What it is |
|------|-----------|
| `DSH.md` | Home / map of content — start here |
| `Concepts/` | The three design directions ([[Aurora]], [[Aurora v2]], [[Conversational Cockpit]]) |
| `Sentinel/` | The [[DSH Sentinel]] bot + its six engine notes |
| `Architecture/` | [[Live Trading Blueprint]] and [[Realtime Data Flow]] |
| `Roadmap.md` | The phased plan |
| `Engines.base` | Live table/board over the engine notes |
| `Architecture.canvas` | The whole system on one board |

## Built with

The notes, the `.base`, and the `.canvas` follow the
[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills) conventions —
Obsidian-flavored markdown, Bases, and JSON Canvas.

> [!note] Two homes for the same project
> The interactive HTML mockups live in the repo root (`design-concepts/`,
> `docs/`, `dsh-living-bot.html`). This vault is the *thinking* layer that links
> them together.
